Montar um portfólio pessoal nunca foi tão acessível. Com frameworks como Next.js e MDX para conteúdo, dá para ter um site performático e fácil de manter.

## Por que Next.js?

O Next.js oferece renderização no servidor de fábrica, o que ajuda os mecanismos de busca a indexar seu conteúdo desde a primeira carga. O App Router traz roteamento por arquivos e layouts que deixam o projeto organizado. Com otimização de imagem embutida, você tem uma base sólida para qualquer portfólio.

## Conteúdo com MDX

MDX permite escrever Markdown com componentes JSX. Dá para embutir elementos interativos, destaques personalizados ou demos de código direto no post. É um bom equilíbrio entre simplicidade e poder para texto técnico.

## Pontos principais

- Use o App Router para layouts limpos e aninhados
- Use MDX para conteúdo rico com componentes
- Otimize imagens com `next/image` para melhor desempenho
- Mantenha o conteúdo versionado junto com o código

Seja para mostrar projetos de dev ou trabalho criativo, um stack moderno assim atende bem.
