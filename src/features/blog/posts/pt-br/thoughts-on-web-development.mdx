O cenário de desenvolvimento web muda rápido. Novos frameworks, bundlers e paradigmas surgem todo ano. Aqui vão algumas ideias sobre o que permanece estável no meio do barulho.

## As ferramentas não param de mudar

De jQuery a React, de Webpack a Turbopack: a ferramenta evolui. O que importa é dominar o básico: HTML, CSS e JavaScript. Tudo o mais se apoia nisso. Com a base sólida, novidades ficam mais fáceis.

## Performance ainda importa

As pessoas esperam carregamento instantâneo. Core Web Vitals não são só números — afetam como o trabalho é vivido. Lazy loading, code splitting e gestão de assets continuam essenciais, independente do framework.

## Experiência do desenvolvedor

Boa DX não é luxo. Hot reload, tipagem e erros claros deixam o dia a dia mais rápido e menos frustrante. Vale investir no setup; o retorno vem ao longo do projeto.

## Lance

O melhor portfólio é o que existe. Perfeito é inimigo do feito. Comece simples, itere e mostre seu trabalho. O resto vem depois.
