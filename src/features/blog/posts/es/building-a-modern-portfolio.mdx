Crear un portafolio personal nunca ha sido tan sencillo. Con frameworks como Next.js y el poder de MDX para el contenido, puedes tener un sitio rápido y agradable de mantener.

## ¿Por qué Next.js?

Next.js ofrece renderizado en el servidor desde el primer momento, lo que ayuda a que los buscadores indexen tu contenido desde la primera carga. El App Router aporta rutas basadas en archivos y layouts que organizan el proyecto de forma intuitiva. Con la optimización de imágenes integrada, tienes una base sólida para cualquier portafolio.

## Contenido con MDX

MDX te permite escribir Markdown con componentes JSX. Puedes incrustar elementos interactivos, avisos personalizados o demos de código directamente en tus entradas. La mezcla de simplicidad y potencia lo hace ideal para divulgación técnica.

## Ideas clave

- Usa el App Router para layouts claros y anidados
- Aprovecha MDX para contenido enriquecido con componentes
- Optimiza imágenes con `next/image` para mejor rendimiento
- Mantén el contenido en control de versiones junto al código

Tanto si eres desarrollador mostrando proyectos como si compartes trabajo creativo, un stack moderno como este te servirá bien.
